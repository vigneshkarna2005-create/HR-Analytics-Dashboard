# HR Analytics Dashboard

## Project Overview
An interactive HR Analytics Dashboard built using Microsoft Excel to analyze employee data and provide insights into workforce demographics, salary, and attrition.

## Objectives
- Analyze employee count and workforce distribution
- Understand employee demographics by gender, department, and job role
- Analyze average, minimum, and maximum salary
- Analyze average employee age
- Monitor employee attrition rate
- Present HR insights through interactive charts and filters

## Key KPIs
- Employee Count
- Average Age
- Average Salary
- Maximum Salary
- Minimum Salary
- Attrition Rate

## Dashboard Features
- Interactive slicers for Gender, Department, Job Role, Attrition, and Education Field
- Salary analysis
- Employee distribution analysis
- Gender distribution
- Department-wise analysis
- Interactive charts and KPI cards

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel formulas

- `HR Dashboard Project.xlsx` – Excel dashboard and underlying data
